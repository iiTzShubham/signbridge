# SignBridge experimental methodology

The comparison runs `cnn_lstm` and `vit_temporal` serially on the same CSV manifest, class-to-index map, seed, and held-out split. The manifest records clip path, gloss, signer ID, split, and frame bounds. Split modes: `provided` keeps official WLASL splits; `signer-independent` groups by signer; `stratified` splits each word's clips at random (used for WLASL-100 here, because only half the clips were available). Experiment 2 uses a combined manifest (`datasets/build_combined_manifest.py`): WLASL-100 train/val plus ASL Citizen's official train/val, with ASL Citizen's signer-independent test set as `test` and the WLASL-100 test set kept as the extra split `test_wlasl`. Never compare results across differing manifests as paired results.

Each video is sampled at uniformly spaced frame indices, resized to the configured square image size, converted to RGB, and normalized with ImageNet channel statistics. Both models use ImageNet-pretrained spatial backbones where configured. The CNN-LSTM applies ResNet-50 features per frame and an LSTM over the clip. The temporal ViT applies ViT-B/16 features per frame followed by an explicit Transformer encoder over frame embeddings. By default the pretrained spatial backbones are frozen; temporal layers and classification heads are trained. With `cache_features`, the frozen backbone is run once per clip (plus `feature_views` augmented views: time jitter, 80-100 % crop, horizontal flip) and the cached features train the head; the test split is still evaluated with the full model on raw video.

Training minimizes cross-entropy (optional label smoothing) using AdamW and a ReduceLROnPlateau schedule. The validation metric named by `checkpoint_metric` (`val_loss` or `val_top1`) selects the saved checkpoint, with early stopping. The test partition is used once after selecting the checkpoint, and any `extra_test_splits` are evaluated with the same checkpoint. Macro precision/recall/F1 average over the classes present in each test set. Top-5 is omitted only if fewer than five classes exist.

Inference latency is mean per-video model forward-pass time, measured after configurable warm-up batches with accelerator synchronization. The time excludes decoding, frame extraction, and preprocessing; FPS is processed sampled frames divided by total measured model forward time. This is not end-to-end application latency. Peak memory is a sampled process RSS or accelerator allocator/driver measure, not total system usage.

One seed yields preliminary results only. For repeated seeds, tables show arithmetic mean and sample standard deviation. No significance test or p-value is emitted. A future test must respect paired seeds and the independent unit of analysis (typically signer or video, depending on the study design).

## Dataset handling

WLASL annotations and video files are subject to the dataset terms. Obtain videos through the official WLASL maintainers after reviewing the repository's C-UDA terms. Do not redistribute the videos with this project. See the official [WLASL repository](https://github.com/dxli94/WLASL).

ASL Citizen clips (Experiment 2) are fetched with `experiments/download_asl_citizen_subset.py` and are covered by the Microsoft Research licence in `datasets/ASL-Citizen/use.txt`: non-commercial research only, no redistribution, and no inclusion of the videos in publications or presentations. See the [ASL Citizen project page](https://www.microsoft.com/en-us/research/project/asl-citizen/).
