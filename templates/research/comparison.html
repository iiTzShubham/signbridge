FROM SETUP TO FINDINGS

How to get your first results

Four small steps take you from the dataset to a side-by-side comparison.

one step
at a time ✦
01

Prepare the dataset

Place WLASL videos and its annotation file in datasets/WLASL-100/.

Read dataset instructions ↗
02

Build and check the video list

This creates the shared class labels and train, validation, and test split.

03

Train and compare

Both models train with the same data and are measured on the held-out test split.

04

Bring results into this page

Import completed measurements to update the scorecard and download the report.

✦

First time setting up? Install the ML tools first with python -m pip install -r requirements-ml.txt, then validate your manifest with python datasets/validate_manifest.py --manifest datasets/WLASL-100/manifest.csv --dataset-root datasets/WLASL-100 --classes 100.
